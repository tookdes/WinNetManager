| 标签页 | 功能 | 数据来源 |
|--------|------|----------|
| **跃点数** | 统一管理网卡基础跃点和默认网关路由跃点，直观干预多网卡的流量优先级走向 | PowerShell NetTCPIP |
| **IP 配置** | 增强：增加网卡安全重启功能（防止远程断连），支持批量操作 | ipconfig / PowerShell |
| **DNS** | 增强：增加常规网卡基础 DNS 管理功能（原仅有 NRPT 规则） | PowerShell DnsClient |
| **自动化监控** | 新增：IFTTT 式规则引擎（三态条件树 AND/OR + 时间门槛 + 动作链），内置 4 大场景模板（IPv6 自愈升级梯 / IPv4 掉线重启+通知 / A、B 全挂走 C 或 SOCKS5 / 网络配置文件整理），默认 dry-run，破坏性动作全局串行 + 熔断 + 预算 + 抑制窗口 + JSONL 审计 | WinNetManager.Core 引擎 |

本次更新重点加入了全局网卡及网关跃点管理，以及补齐了基础的网卡 DNS 服务器配置和防断联网卡重启功能。 本次新增了「自动化监控」标签页：一套以共享探针为核心的规则引擎，支持三态条件（含 Unknown 不误判）、连续次数/持续时长/滑窗时间门槛、动作链 fallback 与 StopOnFailure、重启抑制窗口、全局熔断与预算、规则导入导出与 JSONL 审计；内置 4 个场景模板一键生成，新规则与导入规则默认 dry-run，需显式开启才会真正执行。
